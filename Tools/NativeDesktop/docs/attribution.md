## PCController font replacement

This PCController adaptation uses `assets/fonts/Vazirmatn-Regular.ttf`, copied
from PCController's existing mobile font asset. Vazirmatn is also the Persian
family used by the PCController WebUI. Its SIL Open Font License 1.1 is included
as `assets/fonts/OFL.txt`. Windows uses Segoe UI for normal UI text. The original
YekanBakh asset is excluded from the current build tree; its historical import
remains in Git provenance, not in packaged PCController assets.

## Platform APIs and formats

RayanLamp interoperates with Microsoft Windows APIs and formats, including
DWM, Win32 notifications, WinMM audio, Task Dialog, COM Automation, named
pipes, registry Run entries, VT100 console mode, ICO, VERSIONINFO, application
manifests, and WM_COPYDATA, plus the browser Web Audio API. References to
Microsoft product/API names are descriptive and do not imply endorsement.

PNG, APNG, RIFF, and PCM WAV are file formats. ImageMagick is an external
development tool used when regenerating visual assets; it is not distributed
with or required to run RayanLamp. The Go SFX generator has no external
encoder dependency.

## Maintaining notices

Before a release:

1. Run `go list -mod=mod -m all` and compare it with this table.
2. Review the exact license file for every new or upgraded module.
3. Confirm any new visual asset's provenance and compatible license.
4. Preserve any binary-redistribution notices required by the final
   single-file artifact.
