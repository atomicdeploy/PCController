OFFLINE CONTRACT · LIVING API

PCController API

The primary host exposes one unversioned living surface across REST, JSON-RPC, WebSocket, and the bounded Socket.IO adapter. In this alpha build authentication and authorization are deliberately disabled until issue #148; remote exposure still requires an explicit listener and Origin allow-list.
